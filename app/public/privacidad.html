Política de Privacidad

Rayando el CDA · última actualización: 26 de julio de 2026

1. Alcance de esta política

Esta política describe cómo Rayando el CDA maneja los datos en el contexto de su integración con TikTok for Developers, usada para publicar automáticamente clips del programa en la cuenta oficial @rayandoelcda. No aplica a datos de otros usuarios de TikTok, ya que esta integración no interactúa con cuentas de terceros.

2. Qué datos se recopilan

  • Un token de acceso de la propia cuenta de TikTok de Rayando el CDA (@rayandoelcda), autorizado por su administrador para permitir la publicación automática de contenido.
  • No se recopilan datos personales de espectadores, seguidores u otros usuarios de TikTok.
  • No se accede a mensajes privados, contactos ni datos de terceros a través de esta integración.

3. Cómo se usan estos datos

El token de acceso se usa exclusivamente para publicar, mediante la Content Posting API de TikTok, los videos verticales que produce Rayando el CDA a partir de su programa. No se usa con ningún otro fin.

4. Con quién se comparten

Estos datos no se venden, alquilan ni comparten con terceros. Solo son accedidos por el equipo técnico de Rayando el CDA para operar la publicación automática.

5. Almacenamiento y seguridad

El token de acceso se guarda en variables de entorno del servidor que ejecuta el proceso de publicación, fuera de cualquier repositorio público, y no queda expuesto a usuarios finales.

6. Control y revocación

El administrador de la cuenta @rayandoelcda puede revocar el acceso de esta integración en cualquier momento desde la configuración de aplicaciones conectadas en TikTok, deteniendo de inmediato cualquier publicación automática futura.

7. Cambios en esta política

Esta política puede actualizarse. La fecha de la última actualización queda indicada arriba.
